FRANÇAIS

Point de vente — guide rapide

GSTAAD SAANENLAND TOURISMUS · billets du Gstaad New Year Music Festival

1Vos accès

Adresseticketick.ch/login
E-mailfrieder.class@gstaad.ch
Mot de passetransmis séparément

Code de sécurité. Après le mot de passe, un code à 6 chiffres arrive par e-mail. Saisissez-le pour entrer (valable 10 minutes). Sur le même appareil, il n'est redemandé qu'environ une fois par semaine, ou après une déconnexion.

Rien reçu ? Regardez dans les indésirables, puis Envoyer un nouveau code. Un code reçu sans avoir tenté de vous connecter : changez le mot de passe et prévenez-nous.

À la première connexion, changez le mot de passe : icône du compte en haut à droite → Mon espace → Mot de passe (12 caractères au moins). Oubli : Mot de passe oublié ? sur la page de connexion.

2Vendre des billets

  1. Onglet Vendre → choisissez le concert.
  2. Places — Choisir sur le plan : touchez les places (violettes une fois choisies, grises si déjà prises), puis choisissez le tarif de chaque place sous le plan. Ou Attribution automatique : indiquez les quantités, les meilleures places libres sont attribuées.
  3. Client (facultatif) : le nom est imprimé sur les billets ; avec son e-mail, le client reçoit ses billets.
  4. Encaissement — Espèces : encaissez puis validez. Carte en ligne : un QR code s'affiche ; le client paie avec son téléphone ou sur votre écran. Sans paiement dans les 2 heures, les places sont libérées.
  5. Billets (PDF) pour imprimer, puis Nouvelle vente.

Chaque billet porte « Vendu par GSTAAD SAANENLAND TOURISMUS, en espèces / par carte, le … à … ». Tarif Moins de 25 ans : gratuit, nominatif, avec au moins un billet payant ; pièce d'identité demandée à l'entrée.

3Suivre les ventes

  • Ventes : toutes vos ventes et leur état. Ouvrez une vente pour réimprimer les billets ; carte en attente : Nouveau QR code ou Vérifier le paiement.
  • Vue d'ensemble : billets, montants et votre commission (10 %), concert par concert.

4Décompte avec le festival

EncaissementQui a l'argentRésultat
EspècesVousVous gardez 10 % et reversez 90 % au festival
CarteLe festivalLe festival vous doit 10 %

Le solde figure dans Vue d'ensemble → décompte avec l'organisateur.

Annulation, erreur de vente ou problème d'accès : support@ticketick.ch
DEUTSCH

Verkaufsstelle — Kurzanleitung

GSTAAD SAANENLAND TOURISMUS · Tickets für das Gstaad New Year Music Festival

1Ihr Zugang

Adresseticketick.ch/login
E-Mailfrieder.class@gstaad.ch
Passwortwird separat mitgeteilt

Sicherheitscode. Nach dem Passwort erhalten Sie einen 6-stelligen Code per E-Mail. Geben Sie ihn ein, um sich anzumelden (10 Minuten gültig). Auf demselben Gerät wird er nur etwa einmal pro Woche oder nach einer Abmeldung erneut verlangt.

Nichts erhalten? Sehen Sie im Spam-Ordner nach und tippen Sie dann auf Neuen Code senden. Ein Code, ohne dass Sie sich anmelden wollten: Ändern Sie das Passwort und benachrichtigen Sie uns.

Bei der ersten Anmeldung ändern Sie bitte das Passwort: Konto-Symbol oben rechts → Mein Konto → Passwort (mindestens 12 Zeichen). Vergessen: Passwort vergessen? auf der Anmeldeseite.

2Tickets verkaufen

  1. Reiter Verkaufen → Konzert wählen.
  2. Plätze — Auf dem Saalplan wählen: Plätze antippen (violett = gewählt, grau = bereits vergeben), dann unter dem Plan für jeden Platz den Tarif wählen. Oder Automatische Zuteilung: Anzahl angeben, die besten freien Plätze werden zugeteilt.
  3. Kunde (freiwillig): Der Name wird auf die Tickets gedruckt; mit seiner E-Mail erhält der Kunde die Tickets direkt.
  4. Zahlung — Bar: kassieren und bestätigen. Online-Kartenzahlung: Ein QR-Code erscheint; der Kunde zahlt mit seinem Handy oder auf Ihrem Bildschirm. Ohne Zahlung innert 2 Stunden werden die Plätze freigegeben.
  5. Tickets (PDF) zum Drucken, dann Neuer Verkauf.

Jedes Ticket trägt den Vermerk «Verkauft von GSTAAD SAANENLAND TOURISMUS, bar / mit Karte, am … um …». Tarif Unter 25 Jahren: kostenlos, auf den Namen, nur mit mindestens einem bezahlten Ticket; Ausweis beim Eingang.

3Verkäufe verfolgen

  • Verkäufe: alle Ihre Verkäufe mit Status. Verkauf öffnen, um Tickets erneut zu drucken; offene Kartenzahlung: Neuer QR-Code oder Zahlung prüfen.
  • Übersicht: Tickets, Beträge und Ihre Kommission (10 %) pro Konzert.

4Abrechnung mit dem Festival

ZahlungWer hat das GeldErgebnis
BarSieSie behalten 10 % und überweisen 90 % ans Festival
KarteDas FestivalDas Festival schuldet Ihnen 10 %

Den Saldo finden Sie unter Übersicht → Abrechnung mit dem Veranstalter.

Stornierung, Fehler beim Verkauf oder Zugangsproblem: support@ticketick.ch
