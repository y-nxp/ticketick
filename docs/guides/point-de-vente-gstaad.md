# Point de vente ticketick — guide rapide

**GSTAAD SAANENLAND TOURISMUS** · billets du **Gstaad New Year Music Festival**

## 1. Vos accès

| | |
|---|---|
| Adresse | <https://ticketick.ch/login> |
| E-mail | frieder.class@gstaad.ch |
| Mot de passe | transmis séparément |

**À la première connexion**, changez le mot de passe : icône du compte en haut à droite → **Mon espace** → section **Mot de passe** (12 caractères au moins).

**Code de sécurité** : après le mot de passe, un code à 6 chiffres arrive par e-mail sur frieder.class@gstaad.ch. Saisissez-le pour entrer. Il est valable 10 minutes. Sur le même appareil, le code n'est redemandé qu'une fois par semaine environ, ou après une déconnexion.

- Rien reçu ? Regardez dans les indésirables, puis touchez **Envoyer un nouveau code**.
- Code inattendu, alors que personne ne se connecte ? Changez le mot de passe et prévenez-nous.
- Mot de passe oublié : lien **Mot de passe oublié ?** sur la page de connexion.

## 2. Vendre des billets

1. Onglet **Vendre** → choisissez le concert et la date.
2. **Places** :
   - **Choisir sur le plan** : touchez les places voulues (en violet une fois choisies, en gris quand elles sont déjà prises). Sous le plan, choisissez le tarif de chaque place. Une croix retire une place.
   - **Attribution automatique** : indiquez seulement les quantités par tarif, les meilleures places libres sont attribuées.
3. **Client** (facultatif) : le nom est imprimé sur les billets ; avec l'e-mail, le client reçoit ses billets directement.
4. **Encaissement** :
   - **Espèces** : encaissez, puis touchez **Encaisser … en espèces**.
   - **Carte en ligne** : un QR code s'affiche. Le client le scanne avec son téléphone et paie par carte, ou paie directement sur votre écran. Les billets partent dès le paiement. Sans paiement dans les 2 heures, les places sont libérées.
5. **Billets (PDF)** pour imprimer, puis **Nouvelle vente**.

Chaque billet porte la mention « Vendu par GSTAAD SAANENLAND TOURISMUS, en espèces / par carte, le … à … ».

Tarif **Moins de 25 ans** : gratuit, nominatif (nom et date de naissance), uniquement avec au moins un billet payant ; une pièce d'identité est demandée à l'entrée.

## 3. Suivre les ventes

- **Ventes** : toutes vos ventes, avec leur état (payée, en attente, non payée). Ouvrez une vente pour réimprimer les billets. Pour une vente par carte en attente, **Nouveau QR code** ou **Vérifier le paiement**.
- **Vue d'ensemble** : billets vendus, montants et votre commission (10 %), concert par concert.

## 4. Décompte avec le festival

| Encaissement | Qui a l'argent | Résultat |
|---|---|---|
| Espèces | Vous | Vous gardez vos 10 % et reversez 90 % au festival |
| Carte | Le festival | Le festival vous doit 10 % |

Le solde net figure dans **Vue d'ensemble → Décompte avec l'organisateur**.

## 5. Besoin d'aide

Annulation, erreur de vente ou problème d'accès : **support@ticketick.ch**.
